# Databricks Cluster Intelligence & Autonomous Governance Agent

An autonomous FinOps, HIPAA compliance, and workload right-sizing agent for Databricks compute resources built with Google Gemini 2.0 and the ADK Agent Development Kit.

---

## 🌟 Overview

The **Databricks Cluster Intelligence & Autonomous Governance Agent** helps Data Platform Engineers and FinOps leaders inspect, optimize, and govern Databricks compute clusters. It identifies policy compliance violations, right-sizes oversized worker nodes, predicts Photon Engine acceleration speedups, and logs audit trails directly to Google Cloud Firestore.

---

## ☁️ Google Cloud Services & Infrastructure

The codebase in `app/` is actively wired to the following Google Cloud services:

- **Vertex AI Memory Bank (`PreloadMemoryTool` & `after_agent_callback`)**: Persists cross-session user preferences, cost center budget limits, and user profile data across conversations.
- **Google Cloud Firestore (`databricks_clusters` collection)**: Reads live cluster states, mutates node configurations, and writes timestamped before/after audit trails into `recommendation_history`.
- **Google Cloud Storage (GCS)**: Stores 3D motion graphic preview videos generated by the agent and returns public HTTPS URLs without local file I/O.
- **Vertex AI Omni Model (`gemini-omni-flash-preview`)**: Calls the Vertex AI Interactions API in the `global` region to generate 3D motion visualizations and saves them as artifacts via `tool_context.save_artifact`.
- **Vertex AI Agent Engine Code Sandbox (`AgentEngineSandboxCodeExecutor`)**: Executes python code securely within an isolated Agent Engine sandbox for financial modeling and sizing calculations.

## 🛠️ Implemented Tool Catalog

### 🛰️ Module 1: Telemetry & Live Discovery
- `list_databricks_clusters(state_filter)`: Queries cluster configuration records from Firestore.
- `fetch_live_databricks_clusters(cluster_id)`: Fetches live cluster status via Databricks REST API wrappers.
- `query_databricks_system_tables(table_name, cluster_id)`: Queries Databricks System Tables telemetry (`system.billing.list_prices`, `system.query.history`, `system.lakeflow.jobs`, `system.compute.clusters`, `system.compute.warehouses`).

### ⚡ Module 2: Unified Workload & Sizing Engine
- `analyze_unified_workload_and_scaling_efficiency(cluster_id)`: Derives Workload Code Inefficiencies vs Compute Capacity Bottlenecks, horizontal/vertical scaling bounds, and time-of-day autoscale bounds.
- `analyze_advanced_cluster_telemetry_and_anomalies(cluster_id)`: Detects cost anomalies and non-auto-terminated idle clusters.
- `analyze_job_workloads_and_recommend_scaling(cluster_id)`: Evaluates scheduled job runs and recommends optimal min/max worker ranges.
- `analyze_workload_vs_cluster_efficiency(cluster_id)`: Computes workload efficiency scores and sizing balance.

### 🛡️ Module 3: Governance, Compliance & Guardrails
- `audit_cluster_policy_compliance_and_remediations(cluster_id)`: Audits Databricks Cluster Policy compliance (HIPAA / PHI workloads, Unity Catalog required, Single-User mode, approved LTS Photon runtimes, No Public IP) and provides remediation guidance.
- `audit_cluster_health_and_spot_risk(cluster_id)`: Audits Spot Instance interruption risk and mandatory tag governance.
- `audit_budget_guardrails_and_quotas(cluster_id)`: Audits Cost Center budget limits and monthly DBU quota compliance.

### 🚀 Module 4: Compute Modernization & Video Generation
- `predict_photon_acceleration_and_speedup(cluster_id)`: Predicts 13.3 LTS Photon acceleration speedups and net DBU savings.
- `evaluate_serverless_compute_migration(cluster_id)`: Identifies ETL pipelines and SQL Warehouses candidate for Databricks Serverless Compute migration.
- `generate_domain_video_preview(item_description, tool_context)`: Generates a short 3D motion graphic preview using `gemini-omni-flash-preview` in the `global` region, saves to Playground artifacts via `tool_context`, and uploads bytes to GCS.

### 📊 Module 5: Financial Dashboards & Audit History
- `get_ops_dashboard()`: Renders an executive FinOps & Governance visual dashboard.
- `calculate_cluster_resizing_savings(cluster_id, target_workers)`: Computes projected monthly DBU savings from worker right-sizing.
- `apply_right_size_recommendation_with_history(cluster_id, target_workers)`: Applies worker scale adjustments in Firestore and logs Before vs. After audit records.
- `update_cluster_recommendation(cluster_id, recommendation)`: Updates Firestore recommendation status.
- `get_recommendation_history(cluster_id)`: Retrieves historical audit logs for cluster changes.

## 🚀 Setup & Execution Instructions

### Prerequisites
- **Python 3.11+**
- **uv**: Package installer (`pip install uv` or `curl -LsSf https://astral.sh/uv/install.sh | sh`)
- **agents-cli**: Agents CLI tool (`uv tool install google-agents-cli`)
- **Google Cloud SDK**: Authenticated via `gcloud auth application-default login`

### Installation

```bash
# Clone the repository
git clone https://github.com/deepacts/buildwithgemini-databricks-cluster-intel-agent.git
cd buildwithgemini-databricks-cluster-intel-agent

# Install dependencies with agents-cli
agents-cli install
```

### Running Locally

```bash
# Launch local development playground
agents-cli playground
```

### Running Tests

```bash
# Run unit and integration tests
uv run pytest tests/integration/test_agent.py
```

### Deploying to Vertex AI Agent Runtime

```bash
# Set GCP project and deploy
gcloud config set project <your-gcp-project-id>
agents-cli deploy --project <your-gcp-project-id> --region us-east1
```
